Problem Description:

1.The problem the program is solving is allowing the computer company to have
a program that will allow the computer company to store and evaluate sales data
and determine the consecutive period of months with the highest combined sales
change.

2.The program receives data on the name of the months within a year and the
sales change that corresponds with each month.

3.The result the program should produce is the starting month and ending month of
the period with highest consecutive sales change after observing the consecutive
periods and calculating which period had the highest sales change.

Data Design:
I plan to store the month names in a String array. I will be storing the sales
value in a double array.The same array index can connect a month with its sales
value by using two different arrays that connect with the same index
